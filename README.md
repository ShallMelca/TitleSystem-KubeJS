# 称号システム更改

## 新規に実装するコマンド

- 表示する称号を選べるコマンド (ex /choice mineChamp)
- 持ってる称号を表示するコマンド (ex /showTitle)
- 称号apply処理を手動実行するコマンド (ex /appTitle)

## 称号の種類

現状の保存方法が使えるならそのままでもおｋ。

- ランキング型
  - server.persistentData.kings 以下に保存

- 実績（挑戦）取得に伴う解放型
  - player.persistentData.kings に配列で保持
  - ["panda", "masterChef", ...]的な。
  - 一度解放すれば、常に称号設定できる

## 称号の付け方

### 自動処理

- プレイヤー1人を専用のチームに突っ込む（全員自動的に）
- ランキング型称号を自動更新
  - 更新間隔は 1-5分程度
- 挑戦を解放したら、解放型称号を自動付与

### ユーザ処理

- コマンドで、持ってる称号を確認する
- ユーザはコマンドで、どの称号を表示するか選ぶ
  - 選択したら称号切替処理を自動実行させる
- 称号がなぜか取れてたとき用→付け直せる
